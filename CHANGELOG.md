# Changelog

## 1.0.0

Initial public Windows release.

- First-run LAN setup and discovery, saved lights, room organization, and controls based on each device's capabilities.
- Live brightness, a radial color wheel, and a white warmth slider.
- Named presets with offline preflight and restoration after partial failures.
- User-selected screen-sync groups with shared GPU capture and independent region assignments.
- Individual-member controls and segmented layouts for compatible sets, including zone selection, side swap, vertical flips, and a live preview.
- Stable screen sampling, Comfort processing, warm/cool color ranges, and adaptive device traffic limits.
- Dark Windows UI, system tray controls, optional sign-in startup, and automatic resume with delayed-network retry.
- Opt-in local MCP access, per-light permissions, and a desktop plugin for AI controls and temporary task notifications.
- Source build scripts, portable packaging, and isolated regression tests.

See the [compatibility guide](docs/COMPATIBILITY.md) for model-specific features and limits.
