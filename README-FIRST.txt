Govee Lights 1.0.0
Windows 11 x64

Extract this ZIP into a permanent folder. Keep the extracted files together,
then open Govee Lights.exe.

ENABLE LAN CONTROL FOR EACH LIGHT
In Govee Home, open the light, select Settings (gear), and turn on LAN Control.
Repeat for every light you want to add. The light and PC must share the same
local network. A model must offer LAN Control to connect here.

Use Lights > Find lights to add devices. Edit a light to give it a name and room.
Manual controls and presets are available independently of screen sync.
Brightness, the radial color wheel, and the white warmth slider adjust live.
Check Include in screen sync only for the lights you want to follow the screen.
Assign each light a screen region regardless of its location in the room.
Supported segmented sets offer additional sampling zones and a layout preview.
Comfort softens bright peaks and strong colors without adding a fade queue.
Use 0% and Full spectrum to retain sampled colors, or try Warm / Cool range.

Compatible sets offer individual member color and relative intensity controls.
Individual control runs while the app is open or in the tray. Release bars
restores the previous lighting. Power and white warmth apply to the entire set;
release individual control before saving a preset. Model-specific features and
supported layouts are listed in the compatibility guide:
https://github.com/midnitefox/govee-lights/blob/main/docs/COMPATIBILITY.md

Settings contains opt-in Windows sign-in startup and automatic sync resume.
When using startup, keep this folder in its permanent location.
The Close to tray toggle controls what happens when you click X.
Use the tray menu's Quit command to exit completely.

AI CONTROL AND NOTIFICATIONS
Keep Govee Lights MCP.exe with the app. In Settings > AI apps & notifications,
enable access and choose which lights AI apps may control. Copy MCP config
connects a compatible local Windows AI client. The separate OpenAI plugin ZIP
adds task notification skills for local ChatGPT/Codex desktop chats.
Green signals completion, amber attention, red errors, and blue information.
Signals restore lighting and resume interrupted sync. Off lights stay off
unless you enable wake-up. Web/cloud-only chats cannot reach the local app.

This is an unsigned portable release. Available controls depend on the model,
firmware, and bundled device catalog. The compatibility guide lists hardware
coverage and limitations. Setup and troubleshooting are on the repository page.
